# Voyager 文件管理工具开发方案

## 1. 项目目标

Voyager 是一个基于 Wails v2 + Go + Vue 3 + TypeScript + Element Plus 的跨平台桌面文件管理工具，第一版支持 Windows 与 Linux，面向 SMB、WebDAV、FTP 三类远端文件服务。

第一版以“实用 MVP”为目标：用户可以保存连接、测试连接、浏览远端目录，并完成常见文件操作。产品形态先做“远端文件浏览器”，本地/远端双栏管理器作为 V2 演进方向。

## 2. 技术栈

- 桌面框架：Wails v2 稳定版。
- 后端：Go，负责协议连接、文件操作、凭据存储、系统文件对话框、任务状态。
- 前端：Vue 3 + TypeScript + Vite。
- UI：Element Plus + `@element-plus/icons-vue`。
- SMB 客户端候选：`github.com/hirochachacha/go-smb2`。
- WebDAV 客户端候选：`github.com/studio-b12/gowebdav`。
- FTP 客户端候选：`github.com/jlaffaye/ftp`。
- 系统钥匙串候选：`github.com/zalando/go-keyring`。

实施时以最新可用的官方 Wails v2 文档和 `wails doctor` 输出为准锁定版本；依赖版本写入 `go.mod`、`package.json` 和 lock 文件。

## 3. MVP 范围

### 3.1 必须支持

- 连接管理：
  - 新增、编辑、删除连接。
  - 支持 SMB、WebDAV、FTP 三种协议。
  - 支持连接测试。
  - 支持连接名称、主机、端口、用户名、远端根路径等基础配置。
- 凭据管理：
  - 连接配置保存非敏感字段。
  - 密码保存到系统钥匙串。
  - Windows 使用 Credential Manager，Linux 使用 Secret Service / GNOME Keyring 兼容实现。
  - 系统钥匙串不可用时，不保存密码，提示用户本次输入。
- 文件浏览：
  - 列出目录内容。
  - 面包屑导航。
  - 返回上级、刷新当前目录。
  - 显示名称、类型、大小、修改时间。
- 文件操作：
  - 新建文件夹。
  - 重命名。
  - 删除文件或文件夹，删除前二次确认。
  - 上传本地文件到当前远端目录。
  - 下载远端文件到用户选择的本地目录。
- 任务反馈：
  - 上传、下载显示任务状态。
  - 成功、失败、取消状态可见。
  - 错误信息转换为用户可理解的提示。
- 平台支持：
  - Windows 10/11。
  - 主流 Linux 桌面发行版；具体依赖以 Wails v2 `wails doctor` 为准。

### 3.2 暂不支持

- SFTP、FTPS、对象存储、网盘 API。
- 本地/远端双栏拖拽管理。
- 跨协议复制、跨连接复制。
- 文件同步、定时任务、冲突合并。
- 断点续传、秒传、分片上传。
- 文件预览、全文搜索、标签、收藏。
- 高级权限编辑、ACL 管理。
- 多窗口、系统托盘、自动更新。

## 4. 产品形态

主界面采用三段式布局：

- 左侧：连接列表，支持新增、编辑、删除、测试、连接。
- 中间：远端目录浏览区，包含面包屑、工具栏和文件表格。
- 底部或右侧抽屉：传输任务面板，展示上传、下载状态。

核心页面与组件：

- `ConnectionList`：连接列表和连接状态。
- `ConnectionDialog`：新增/编辑连接表单。
- `RemoteBreadcrumb`：远端路径导航。
- `FileToolbar`：上传、下载、新建文件夹、重命名、删除、刷新。
- `RemoteFileTable`：远端文件列表。
- `TransferPanel`：传输任务列表。
- `EmptyState`：未选择连接、目录为空、连接失败等状态。

Element Plus 组件优先使用：

- `ElContainer` / `ElAside` / `ElMain`。
- `ElTable`。
- `ElBreadcrumb`。
- `ElDialog`。
- `ElForm`。
- `ElButton`。
- `ElDropdown`。
- `ElMessage` / `ElNotification`。
- `ElProgress`。

## 5. 系统架构

### 5.1 分层设计

后端按以下边界组织：

- Wails 绑定层：暴露给前端调用的方法，只做参数校验、调用服务和返回结果。
- 应用服务层：连接管理、文件操作、传输任务、错误转换。
- 协议适配层：SMB、WebDAV、FTP 适配统一接口。
- 存储层：连接配置 JSON、本地任务状态、系统钥匙串。
- 平台层：文件选择器、保存目录选择器、系统路径、平台能力判断。

前端按以下边界组织：

- API 层：封装 Wails 生成的 Go 方法调用。
- Store 层：连接列表、当前连接、当前路径、文件列表、任务列表。
- View 层：主界面和连接管理界面。
- Component 层：表格、表单、工具栏、任务面板。
- Type 层：和 Go 返回结构对应的 TypeScript 类型。

### 5.2 推荐目录结构

```text
Voyager/
  app.go
  main.go
  go.mod
  frontend/
    package.json
    src/
      api/
      components/
      stores/
      types/
      views/
      main.ts
      App.vue
  internal/
    appsvc/
    config/
    credential/
    filesystem/
      adapter.go
      smb/
      webdav/
      ftp/
    platform/
    transfer/
```

实际目录以 Wails v2 `vue-ts` 模板生成结果为基础调整，避免重写模板已有约定。

## 6. 后端接口设计

### 6.1 协议统一接口

后端协议适配器提供统一能力：

```go
type FileSystemAdapter interface {
    Test(ctx context.Context) error
    List(ctx context.Context, path string) ([]RemoteEntry, error)
    Mkdir(ctx context.Context, path string) error
    Rename(ctx context.Context, oldPath string, newPath string) error
    Delete(ctx context.Context, path string) error
    Upload(ctx context.Context, localPath string, remotePath string) error
    Download(ctx context.Context, remotePath string, localPath string) error
}
```

所有协议内部使用 `/` 作为远端路径分隔符。适配器负责把统一路径转换为协议库需要的路径格式。

### 6.2 Wails 暴露方法

第一版建议暴露以下方法：

- `ListConnections() ([]ConnectionProfile, error)`。
- `SaveConnection(input ConnectionInput) (ConnectionProfile, error)`。
- `DeleteConnection(id string) error`。
- `TestConnection(input ConnectionInput) error`。
- `ListFiles(connectionID string, path string) ([]RemoteEntry, error)`。
- `CreateFolder(connectionID string, parentPath string, name string) error`。
- `RenameEntry(connectionID string, oldPath string, newName string) error`。
- `DeleteEntry(connectionID string, path string) error`。
- `PickUploadFiles() ([]string, error)`。
- `UploadFiles(connectionID string, remoteDir string, localPaths []string) ([]TransferTask, error)`。
- `PickDownloadDirectory() (string, error)`。
- `DownloadFile(connectionID string, remotePath string, localDir string) (TransferTask, error)`。
- `ListTransferTasks() ([]TransferTask, error)`。

上传和下载通过 Go 后端调用系统文件对话框获取本地路径，避免在前端直接处理受限文件路径。

## 7. 协议实现要点

### 7.1 SMB

- 默认端口：445。
- 连接配置至少包含：host、port、share、username、password、domain 可选。
- 使用 SMB2/SMB3 客户端库直接访问共享，不依赖操作系统挂载。
- 路径格式：连接级别保存 share，文件操作路径只表示 share 内路径。
- 风险：不同 Windows Server、Samba、NAS 的 SMB 能力存在差异，MVP 阶段必须纳入手工兼容性测试。

### 7.2 WebDAV

- 默认端口：HTTP 80，HTTPS 443。
- 连接配置至少包含：baseURL、username、password、rootPath 可选。
- MVP 支持 Basic Auth。
- 优先支持 HTTPS；HTTP 允许使用，但连接表单需要给出安全提示。
- 路径格式：rootPath + 当前远端路径。

### 7.3 FTP

- 默认端口：21。
- 连接配置至少包含：host、port、username、password、rootPath、passiveMode。
- MVP 支持普通 FTP，不支持 SFTP；FTPS 作为后续扩展评估。
- 普通 FTP 明文传输，连接表单需要给出安全提示。
- 下载时先写入临时文件，成功后再移动到目标文件名，降低半成品文件风险。

## 8. 数据与凭据存储

### 8.1 连接配置

连接配置保存到用户配置目录：

```text
{UserConfigDir}/Voyager/connections.json
```

配置文件保存：

- connection id。
- name。
- protocol。
- host / port / baseURL / share / rootPath。
- username。
- protocol options。
- credential key。
- createdAt / updatedAt。

配置文件不保存明文密码。

### 8.2 密码

密码保存到系统钥匙串：

- service：`Voyager`。
- account：连接 id 或稳定 credential key。

如果系统钥匙串不可用：

- 保存连接时允许不保存密码。
- 连接时要求用户输入密码。
- UI 明确提示“当前系统钥匙串不可用，密码不会被保存”。

### 8.3 日志与错误

- 日志不得输出密码、完整凭据 URL、认证头。
- 错误提示区分网络不可达、认证失败、权限不足、路径不存在、协议不支持。
- 前端只展示必要错误信息，详细错误可进入开发日志。

## 9. 开发里程碑

### M0：方案与工程初始化

- 创建 Wails v2 `vue-ts` 项目骨架。
- 接入 Element Plus。
- 配置基础 TypeScript、ESLint 或模板默认检查命令。
- 明确 Windows/Linux 开发依赖安装文档。

验收：

- `wails dev` 能启动空应用。
- 前端 TypeScript 检查通过。
- Go 测试命令可运行。

### M1：领域模型与本地存储

- 定义连接配置、远端文件、传输任务类型。
- 实现连接配置读写。
- 实现系统钥匙串读写与不可用降级。
- 暴露连接增删改查和测试连接占位接口。

验收：

- 新增、编辑、删除连接后重启应用仍能恢复。
- `connections.json` 不包含明文密码。
- 钥匙串不可用时 UI 能提示并允许不保存密码。

### M2：WebDAV 适配器优先打通

- 先实现 WebDAV 适配器，用它验证统一文件接口。
- 实现目录列表、新建文件夹、重命名、删除、上传、下载。
- 接入前端文件表格和工具栏。

验收：

- 能连接一个 WebDAV 服务。
- 能完成浏览、上传、下载、新建文件夹、重命名、删除。
- 错误状态能显示清晰提示。

### M3：FTP 与 SMB 适配器

- 实现 FTP 适配器。
- 实现 SMB 适配器。
- 补齐协议特有连接表单字段。
- 统一路径、错误和权限处理。

验收：

- FTP 能完成 MVP 文件操作。
- SMB 能完成 MVP 文件操作。
- 三种协议在前端使用同一套文件浏览界面。

### M4：传输任务与体验完善

- 实现上传/下载任务面板。
- 展示任务状态、开始时间、完成时间、失败原因。
- 支持刷新当前目录和操作后自动更新。
- 增加删除确认、覆盖确认、连接测试反馈。

验收：

- 大文件传输期间 UI 不阻塞。
- 任务成功或失败后状态可追踪。
- 覆盖同名文件前有明确确认。

### M5：跨平台打包与发布准备

- 在 Windows 和 Linux 分别运行 Wails 构建。
- 整理平台依赖说明。
- 准备 README 使用说明。
- 输出基础手工验收清单。

验收：

- Windows 可安装或直接运行构建产物。
- Linux 可运行构建产物，并记录必要系统依赖。
- 三种协议在至少一个测试服务上完成 MVP 验收。

## 10. 验收标准

第一版完成时必须满足：

- 应用可以在 Windows 和 Linux 启动。
- 用户可以创建 SMB、WebDAV、FTP 连接。
- 保存后的连接不在配置文件中暴露明文密码。
- 每种协议至少完成：
  - 测试连接。
  - 浏览目录。
  - 进入子目录和返回上级。
  - 新建文件夹。
  - 上传文件。
  - 下载文件。
  - 重命名文件或文件夹。
  - 删除文件或文件夹。
- 网络错误、认证错误、权限错误、路径不存在都有可理解提示。
- 普通 FTP 和 HTTP WebDAV 在 UI 上有安全提示。
- 操作失败不会导致前端状态卡死。

## 11. 测试策略

### 11.1 Go 后端测试

- 路径规范化单元测试。
- 连接配置读写测试。
- 系统钥匙串封装测试，使用 mock provider。
- 协议适配器契约测试，使用 mock adapter 验证应用服务逻辑。
- 条件允许时，使用本地测试服务做 WebDAV、FTP、SMB 集成测试。

### 11.2 前端测试

- TypeScript 类型检查。
- 连接表单字段切换验证。
- 文件表格空状态、加载状态、错误状态验证。
- 操作按钮在未选中文件、选中文件、选中文件夹时的可用状态验证。

### 11.3 手工验收

- Windows：
  - WebView2 可用。
  - 应用启动、连接、文件操作、下载路径选择正常。
- Linux：
  - Wails 依赖通过 `wails doctor`。
  - 应用启动、连接、文件操作、下载路径选择正常。
  - 系统钥匙串不可用时降级行为正常。

## 12. 风险与应对

- SMB 兼容性风险：不同服务端差异较大。应尽早用 Windows 共享、Samba、常见 NAS 各做一次手工验证。
- Linux 桌面依赖风险：不同发行版 WebKit/GTK 包名不同。以 `wails doctor` 为准，并在 README 记录已验证发行版。
- 系统钥匙串不可用：Linux 最容易出现 Secret Service 缺失。MVP 提供不保存密码的降级路径。
- FTP 安全风险：普通 FTP 明文传输。MVP 允许使用但必须提示风险，FTPS/SFTP 后续再做。
- 大文件传输风险：MVP 不做断点续传。下载使用临时文件，上传/下载失败时任务明确标记失败。
- 删除误操作风险：删除文件或目录必须二次确认，批量删除如果进入 V1 也必须显示数量和目标名称。

## 13. V2 演进方向

- 本地/远端双栏文件管理。
- 拖拽上传、拖拽下载。
- 批量复制、移动、跨目录操作。
- FTPS、SFTP、对象存储。
- 断点续传、传输限速、任务重试。
- 收藏路径、最近连接。
- 文件预览。
- 同步任务。
- 自动更新。
